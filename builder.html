2. Options

Opened by the launcher. Relative links resolve from its folder.

Glob patterns, one per line. Matching files (and the entry page) are placed at the start of the archive and fetched in one request before the app opens.

Glob patterns, one per line. A pattern without “/” matches a name in any folder; dir/** skips a whole folder.

One prefix per line. HTML attributes, CSS url() and JS string literals are rewritten, and an import map covers module paths built at runtime. Other URLs built at runtime (e.g. webpack publicPath: "/") are not found, so building the app with relative URLs is more reliable.

Extra headers added to every file served from the archive, one per line.
